# Joker Sound — Cinematic Landing

This scaffold contains a Vite + React + Tailwind project tailored for Joker Sound. It implements a hero scroll-driven frame animation that uses image frames.

Instructions:

 Or run the included Node script from the project root to copy automatically:

 ```bash
 node scripts/copy_frames.js "c:\\Users\\efems\\OneDrive\\Desktop\\video\\ses sistemi  mp4mp4" ./public/frames
 ```

 After frames are in `public/frames` run:

 ```bash
 npm install
 npm run dev
 ```
